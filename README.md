# Coloxel

Jeu social en pixel art où chaque objet est inventé par un joueur.

```
npm install
npm run dev     # client sur http://localhost:5173, serveur sur http://localhost:3000
npm test
```

- Conception : `docs/conception.md`
- Phase en cours : `docs/phase-1-alpha-solo.md`
- Consignes pour Claude Code : `CLAUDE.md`
- Prototype d'origine : `prototype/atelier-pixel.html` (s'ouvre dans Claude, la génération y passe par ton compte)
